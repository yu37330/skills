# 指標定義ゲート

数値を比較、推奨、継続・撤退条件に使う前に、同じ意味の指標として比較できるか確認する。

## 定義する項目

- 指標名
- 何を1件とするか
- 分子と分母
- 正解・誤りの判定方法と判定者
- 対象範囲と観測期間
- 現状値の出典
- 重大度を区別するか

`精度80％`から`誤り率20％`を自動導出しない。両者が同じ対象、同じ分母、相互排他的かつ網羅的な判定であると確認できた場合だけ補数として扱う。

## 閾値の決め方

数値候補を推奨するには、過去実績、外部基準、許容損失、またはユーザーが選んだリスク水準のいずれかを根拠にする。根拠がなければ推奨値を置かず、自由回答で許容条件を聞く。

安全性を扱う場合は、平均的な発生率だけでなく重大事象の上限を別に定める。

```text
- 全体指標: 定義済みの誤り率がX％以上なら見直す
- 重大度指標: 重大な誤判断が1件でもあれば即時停止・原因確認
```

ユーザーが数値を選んでも、指標定義が未確認なら`仮の閾値`として保存する。Direction Specの`threshold_status`を`proposed`または`unknown`にし、確認済みの決定として表示しない。
