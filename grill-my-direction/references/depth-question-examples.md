# 深掘り質問の例

## 目次

- アンチパターン
- 改善した質問列
- 途中で情報量が変わる場合
- 中心課題が途中で変わる場合
- 質問へ直接答えていない場合
- 抽象方針を具体化する

## アンチパターン

次のような分類質問を連続させない。

1. 誰向けか
2. どのテーマか
3. どの工程か

範囲は狭まるが、なぜ困っているか、何を守るか、何をもって成功・失敗とするかが分からないため、方向性は深まらない。

異なる抽象度の選択肢も避ける。

```text
A: AIを道具として使う        # 方法
B: AIが変える社会を研究する  # 研究目的
C: 研究データ基盤を整備する  # 基盤施策
```

これらは併用でき、同じ判断軸でもない。

## 改善した質問列

### 事前情報が少ない場合

「今後の方向性を考えたい」だけなら、まだ分類や推奨をしない。

```text
質問: 方向性が見つかったとき、今と比べて何がどう変わっていてほしいですか？
なぜ今: 先に望む変化を知ることで、こちらが勝手に問題を定義するのを避けるためです。
```

次は抽象的な自己評価ではなく、具体的な経験を聞く。

```text
直近で「この方向は自分に合っている」と感じた出来事は何でしたか？
```

回答から価値基準や選択肢が現れてから、不足補完と意思決定へ移る。

### 事前情報が十分な場合

資料にゴール、経緯、制約、候補があるなら、背景を再質問せず次のように深掘りする。

### 原因

```text
現在もっとも深刻なボトルネックはどれですか？
A: 必要な情報を見落とす
B: 信頼性の低い情報が混ざる
C: 既存の見方から抜け出せない
```

### 価値衝突

```text
網羅性を上げるために確認作業が増えることと、
確認を減らして見落としが増えることの、どちらをより避けますか？
```

### 境界

```text
効率化しても、最終的に人が保持すべき判断はどれですか？
A: 問いを立てる
B: 根拠を採用・棄却する
C: 結論と説明責任を引き受ける
```

自然に複数該当する場合は「最も委任してはいけないもの」を聞く。

### 反証・撤退

```text
短期実証でどの結果が出たら、この方向を採用しませんか？
A: 品質が基準を下回る
B: 確認工数を含めると時間を削減できない
C: 独自性や説明責任が弱まる
```

### コミットメント

```text
何と比較し、どの閾値を超えたら次段階へ進みますか？
```

期間や閾値をユーザーが選んでいない場合、成果物では「提案」と表示する。

## 途中で情報量が変わる場合

選択式に対してユーザーが経緯や気持ちを文章で返したら、その選択肢では表現できない重要情報がある。文章を要約し、次は自由回答で不足を補う。

```text
理解: 現状への不満より、現在の良さを守りながら将来の選択肢を広げたいのですね。
質問: 5年後に「この方向を選んでよかった」と思える状態を、具体的に描くとどうなりますか？
```

## 中心課題が途中で変わる場合

当初の相談が「収入か安定か」でも、回答から「3年以内の海外転勤」が最優先と分かった場合、海外転勤を新しい中心課題として`problem_frame_version`を更新する。元の収入・安定・AI代替は、新しい中心課題の制約または補助分岐へ付け替える。

この時点でソフト上限へ達しても、必要な経路や適合根拠が未確認なら、すぐ描画選択へ進まず最大3問の再探索枠を使う。

```text
理解: 3年以内の海外転勤が最優先で、現年収の維持が条件です。
現在掘る分岐: 海外転勤を実現する経路
質問: 希望する海外転勤は、現在の会社からの赴任を想定していますか？
```

「海外転勤」を確認せず「海外駐在」と言い換えたり、「それ以外はよい」から現職維持を希望していると補ったりしない。候補比較前の案は`方向仮説（未比較）`とし、`暫定推奨`にはしない。

## 質問へ直接答えていない場合

```text
質問: すでに置き換わり始めた具体的な作業はありますか？
回答: モデルが進化すれば専門知識も代替されそうです。
```

この回答は重要だが、観察事実ではなく将来予測である。次の層へ進まず、次のように一段だけ掘り直す。

```text
理解: 専門知識まで代替される可能性を将来予測として記録します。
質問: 現時点で、以前は人が行っていたがAIで代替できるようになった作業はありますか？なければ「まだ観察していない」で大丈夫です。
```

## 抽象方針を具体化する

```text
回答: 今後は方向づけや意思決定を担える力を伸ばしたいです。
```

この段階で撤退条件を聞かない。先に検証可能な方向仮説へ変える。

```text
質問: 「方向づけ・意思決定を担う」とは、現在よりどんな役割や行動を増やすことですか？
```

役割・行動・期待成果が具体化した後で、その方向が合っていることを示す過去の経験と、見直し条件を聞く。
