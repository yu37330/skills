# SVG制作と品質基準

## 基本構造

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1600 1000" role="img" aria-labelledby="title desc">
  <title id="title">図のタイトル</title>
  <desc id="desc">図の内容を1〜2文で説明</desc>
  <defs><!-- グラデーションやフィルター --></defs>
  <style><!-- 自己完結スタイル --></style>
  <g id="background" />
  <g id="header" />
  <g id="content" />
  <g id="footer" />
</svg>
```

## 制作ルール

- ルート要素に `viewBox`, `role="img"`, `aria-labelledby` を入れる。
- `title` と `desc` を入れる。
- 主要グループとモジュールに意味のある `id` を付ける。
- 文字は `<text>` と `<tspan>` で描き、パス化しない。
- CSSクラスで色と文字スタイルを統一する。
- 角丸、影、罫線の種類は3系統以内にする。
- 接続線は内容より背面へ置き、交差を減らす。
- マーカー矢印は過度に大きくしない。
- 外部リソースを参照しない。

## Editorial Knowledge Map

- タイトルは濃紺・太字で、1〜2行以内にする。
- タイトル直下に、中心主張を収めた横長の白い帯を置く。
- セクション見出しは濃紺、青、青緑の帯に白文字で配置する。
- 本文は白いカードに置き、見出し色と枠線色を所属セクションに合わせる。
- 中央の関係・循環図を最大要素とし、周辺カードより先に読ませる。
- 下段に「新しく生まれる問い」と「実践原則」を並べ、最下部の濃紺帯で結論を再提示する。
- アイコンは2〜3.5pxの単色線画をSVGプリミティブで描き、1カード1個を上限とする。
- 強調色は青、青緑、金の3系統に限定する。

## 日本語組版

- フォントは `Noto Sans JP, Yu Gothic, Meiryo, sans-serif` のフォールバックを使う。
- `editorial-knowledge-map` ではタイトル800、見出し700、本文500相当の太さを使い、細字を避ける。
- 句読点だけを行頭に残さない。
- 改行は意味のまとまりで行い、機械的な固定文字数分割を避ける。
- 英数字と日本語の間隔を不自然に空けない。
- 本文は原則2〜5行、6行を超える場合は再圧縮する。

## 視覚検証

PNGを原寸と50%縮小の両方で確認する。

1. 3秒でテーマと主張が読み取れるか
2. 30秒で構造と主要論点が説明できるか
3. 2分で根拠、制約、示唆まで読めるか
4. 読む順番が視覚的に自然か
5. 説明者がいなくても誤解しにくいか

構造検証が通っていても、目視で問題があれば不合格とする。
